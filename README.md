# Catan Live Dashboard

Ein einfaches HTML/CSS/JavaScript-Dashboard für Catan-Runden mit:

- Live-Standings nach Gesamtpunkten
- Admin-Panel zum schnellen Aktualisieren von Punkten/Aktionen
- Automatischer Punkteberechnung (Siedlungen, Städte, Siegpunktkarten, Sonderboni)
- Live-Spielverlauf (Event-Log)
- Persistenz via `localStorage`

## Start

Einfach `index.html` im Browser öffnen.
